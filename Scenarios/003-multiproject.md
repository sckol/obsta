## Flow
1. Пользователь устанавливает Python-модуль obsta
2. Он создает рабочую папку obsta (по умолчанию ~/.obsta), единую для всех проектов
3. В этой папке запускается общий для всех проектов obstagent, в ней же хранятся сессии [[Агент-исполнитель|агента-исполнителя]] и общий конфиг obstagent, а также скиллы из [[Список скиллов]].
4. Пользователь регистрирует в obstagent папки хранилищ, с которыми он хочет работать
5. При запуске obstagent или добавлении хранилища obstagent переносит в хранилище актуальные версии шаблонов в Conventions/Templates (если такая папка есть, остальные файлы, которые там могут быть, не трогает)~~, устанавливает для хранилища пользовательскую иконку в виде эмодзи фрукта из [[obsta-icons]]~~.
6. obstagent отслеживает каждое хранилище, запуская в каждом не более одной задачи одновременно. Агент-исполнитель должен при этом работать из хранилища как из основной папки, при этом видеть скиллы и другие файлы, которые находятся в рабочей папке obsta
7. При обновлении obsta автоматически происходит ее перезапуск

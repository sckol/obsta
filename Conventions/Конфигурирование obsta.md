## *Формат*
*Общие настройки читаются из [[Configs/obsta]], затем значения из необязательного `Configs/obsta.local.md` заменяют одноимённые общие. Локальный файл исключён из `main`, но сохраняется в локальной `obsta-history`. Значимы строки, начинающиеся с имени в обратных кавычках, знака `=` и значения. Внешние пробелы игнорируются; значение допускает обратные кавычки. Дубликаты внутри каждого файла и ошибочные итоговые значения диагностируются до активации, наблюдение продолжается.*

```text
`nickname` = ``
`subagent` = codex
```
## *Свойства*
- *`nickname` — `[A-Z][A-Z0-9]*`, например `KOL`. В поставляемом общем файле пуст: перед первым запросом укажите свой ник в `Configs/obsta.local.md` или общем файле. Пустое итоговое значение блокирует запуск агента с подсказкой заполнить ник. Задаёт пространство ID `KOL-1`; ветка общая локальная `obsta-history`, ник в её имя не входит.*
- *`subagent` — в этой версии только `codex`; неизвестное значение отклоняет запуск.*

*Номер — максимум корневых компонентов для данного ника плюс один; дочерний — максимум непосредственных детей полного родителя плюс один. Учитываются актуальные границы, исторические заметки и заголовки достижимой `obsta-history`. Старые числовые ID сохраняются отдельным пространством. Одинаковый ник на независимых машинах не гарантирует уникальности; распределённой очереди пока нет.*

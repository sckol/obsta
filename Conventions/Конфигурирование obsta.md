## *Формат*
*Общие настройки читаются из [[Configs/obsta]], затем значения из необязательного `Configs/obsta.local.md` заменяют одноимённые общие. Локальный файл исключён из `main`, но сохраняется в локальной `obsta-history`. Значимы строки, начинающиеся с имени в обратных кавычках, знака `=` и значения. Внешние пробелы игнорируются; значение допускает обратные кавычки. Дубликаты внутри каждого файла и ошибочные итоговые значения диагностируются до активации, наблюдение продолжается.*

```text
`nickname` = ``
`subagent` = codex
```
## *Свойства*
- *`nickname` — `[A-Z][A-Z0-9]*`, например `KOL`. В поставляемом общем файле пуст: перед первым запросом укажите свой ник в `Configs/obsta.local.md` или общем файле. Пустое итоговое значение блокирует запуск агента с подсказкой заполнить ник.
- *`subagent` — в этой версии только `codex`; неизвестное значение отклоняет запуск.*

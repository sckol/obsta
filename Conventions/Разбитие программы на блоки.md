Код программы живет в [[Программный блок|программных блоках]]. Задача-минимум разбивки на блоки - получить работоспособную программу. Задача-максимум - получить работоспособную программу, каждый блок которой может быть автономно пересобран агентом, опираясь только на заметки хранилища и не глядя на предыдущий код.

Пользователь может создавать блоки-файлы и блоки-папки. Создавая блоки-файл, пользователь сам контролирует, из каких файлов состоит его программа. Внутри блока-папки агент имеет право создавать любые файлы самостоятельно.

По каждому блоку создается [[Заметка блока]] в папке Sources, код блока находится в той же папке, что и заметка. Заметка не является программным блоком, а служит его описанием.

Тип блока определяется следующим образом:
- если заметка содержит расширение на конце, например, `myblock.py` (Obsidian автоматически добавляет расширение `myblock.py.md`), то создается программный блок-файл `myblock.py`, который лежит рядом с заметкой. 
- если заметка называется без расширения, например `myblock` (Obsidian автоматически добавляет расширение `myblock.md`), то создается программный блок-папка `myblock`, которая лежит рядом с заметкой.

Агент не имеет права при реализации блока создавать и вносить изменения в другие файлы и папки, кроме самого модуля, его заметки и [[План реализации|плана реализации]], который создается на этапе [[Этап планирования|design spec]].

Программные блоки образуют иерархию. Внутри блока-папки могут находиться другие программные блоки (файлы и папки). Например, если в одном блоке пользователь хочет контролировать реализацию важного алгоритма, файл с этим алгоритмом может быть отдельным блоком-файлом внутри блока-папки. При создании или изменении программного кода [[Glossary/obstagent|obstagent]] работает с каждым блоком последовательно: вносит изменения в один из блоков, проверяет их, только после этого переходит к следующему блоку. Все работы внутри программного блока ведутся с помощью [[Набор скиллов Тесея]].

Конфигурационный файлы блоков либо выносятся в папку Configs (для удобства изменения через Obsidian, см. [[Заметка-конфиг]]), либо управляются через заметки из этой папки по шаблону [[Synced note]].

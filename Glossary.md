# Vault
Папка проекта, в которой хранятся как файлы Obsidian, так и исходные коды и другие файлы, нужные для разрабатываемого проекта
# Ticket
Задача, поставленная агенту в тексте. Каждый тикет имеет номер и фрагмент в определенном документе.
# Ticket mark
Значки, помечающие начало и конец [[#Ticket]].
# Жирный
Текст, выделяемый в Markdown как `**` с обеих сторон.
# Курсив
Текст, выделяемый в Markdown как `*` с обеих сторон.
# Зачеркнутый
Текст, выделяемый в Markdown как `~~` с обеих сторон.
# Комментированный
Текст, выделяемый в Markdown как `%%` с обеих сторон.
# Подчеркнутый
Текст, выделяемый в Markdown как `<u></u>` с обеих сторон.
# sudo-режим агента
Режим, в котором агенту дается полный доступ к хранилищу, в том числе на любое редактирование файлов, их создание и удаление.
# Watcher
Фоновый компонент obsta, реализованный в [[Sources/obsta.py|obsta.py]], который периодически опрашивает Markdown-файлы [[#Vault]], распознаёт команды пользователя и последовательно передаёт их агенту Codex.
